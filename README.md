## Sobre mim

Sou **Fabrício Guimarães**, formado em **Engenharia da Computação** e atualmente **mestrando em Informática pelo IComp/UFAM**, em Manaus.  
Atuo no desenvolvimento de soluções com foco em **arquitetura de software, frontend, backend, dados, microsserviços, automação e inteligência artificial**.

No meu GitHub, você vai encontrar projetos envolvendo:

- **Arquitetura de software**, organização de serviços e desenho de sistemas escaláveis
- **Padrões de projeto** e boas práticas de engenharia para código sustentável
- **Go** para ETL e processamento de dados
- **Python** para automação, IA e APIs
- **JavaScript/TypeScript** para aplicações web
- **React** para interfaces modernas e aplicações frontend
- **Java** e **C#/.NET** em projetos acadêmicos e sistemas
- **PostgreSQL, MySQL, MariaDB e SQL Server** para persistência relacional
- **MongoDB** para modelagem orientada a documentos
- **Redis** para cache, filas e ganho de performance
- **RabbitMQ** e **Celery** para mensageria e processamento assíncrono
- **Docker, FastAPI e CI/CD** em arquiteturas distribuídas e fluxos de entrega

## Projetos em evidência

ETL em **Go** para Dados Abertos do CNPJ, com descoberta via WebDAV, download e extração paralela, carga em PostgreSQL e logs estruturados.

### [todo-list-dupla](https://github.com/abriciof/todo-list-dupla)
Aplicação distribuída com **FastAPI, React, PostgreSQL e Docker Compose**, explorando microsserviços e persistência isolada.

### [one](https://github.com/abriciof/one)
Jogo de cartas estilo Uno desenvolvido em **Java**, executado diretamente no terminal.

### [CRUD-Entity-Framework-WebApi-.NET](https://github.com/abriciof/CRUD-Entity-Framework-WebApi-.NET)
API CRUD com **.NET 8** e **Entity Framework**, focada em operações com banco de dados e estruturação backend.

### [LabPhysics](https://github.com/abriciof/LabPhysics)
Plataforma voltada para aprendizado e simulação de experimentos físicos, com foco educacional e interface web.

### [sistema-neuro-simbolico](https://github.com/abriciof/sistema-neuro-simbolico)
Implementação ligada a **aprendizagem relacional** e **sistemas neuro-simbólicos**, unindo pesquisa e IA.
